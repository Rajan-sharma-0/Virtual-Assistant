## 📌 Project Overview
The **Virtual Assistant** is a smart AI-powered desktop assistant built using Python and PyQt5. It can respond to voice commands, provide useful information, and automate tasks to enhance user productivity.

![Virtual Assistant](assets/virtual_assistant_banner.png)

## ✨ Features
- 🎤 **Voice Command Recognition**
- 🖥️ **Graphical User Interface (GUI) using PyQt5**
- 🔍 **Web Searching Capabilities**
- 📅 **Date & Time Information**
- 🔊 **Text-to-Speech (TTS) Response System**
- 📂 **File and System Operations**
- 📌 **Custom Commands and Task Automation**

## 📂 Project Structure
```
📁 Virtual-Assistant
 ├── 📄 main.py              # Main script to launch the assistant
 ├── 📄 gui.py               # PyQt5 GUI implementation
```

## 🚀 Installation & Setup
### Prerequisites
Ensure you have **Python 3.x** installed on your system.

### Step 1: Clone the Repository
```bash
git clone https://github.com/Rajan-sharma-0/Virtual-Assistant.git
cd Virtual-Assistant
```

### Step 2: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 3: Run the Virtual Assistant
```bash
python main.py
```

## 🛠️ Technologies Used
